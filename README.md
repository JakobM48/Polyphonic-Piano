This is a group project that me and a classmate made for our microcontrollers class.
I was responsible for the coding and the wiring.

This project used accumulator logic in order to achieve polyphony with this pic chip.
The sound was a little crunchy but we believe it gave it some charm, which is why we named it the Buzz Box

This circuit used a potentiometer to the base of a BJT in order to change the volume. A change I would make now is to
replace this BJT with a MOSFET, as different volume selections drastically changed the tone of the sound

This piano also could play 5 octaves, from C2 to B6. There were octave selection buttons which bit-shifted the frequency in order
to half or double it depending on the direction. We just plugged everything into a breadboard and built a nice case around it, and if
I were to reapproach this project I would likely make this project into a PCB to drastically save internal space and make the inside
look like less of a wiring nightmare, since it was a squeeze to fit the assembly together.

Overall, while there were things I would like to improve like volume tone quality, form factor, and crunchiness of multiple notes,
we were very happy with the result, and learned a lot of important lessons along the way.
